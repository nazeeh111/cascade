# Implementation contract (UTC throughout)

DuckDB file: `data/cascade.duckdb`, default schema `main`. CLI uses repository cwd.
`flights`: flight_id VARCHAR, flight_date DATE, carrier VARCHAR, flight_number VARCHAR, tail VARCHAR, origin VARCHAR, dest VARCHAR, sched_dep TIMESTAMP, sched_arr TIMESTAMP, actual_dep TIMESTAMP nullable, observed_gate_out TIMESTAMP nullable (retained regardless of eventual cancellation), actual_arr TIMESTAMP nullable, dep_delay DOUBLE nullable (negative meaningful), arr_delay DOUBLE nullable, cancelled BOOLEAN, diverted BOOLEAN, distance DOUBLE, origin_tz VARCHAR, dest_tz VARCHAR, time_quality VARCHAR, source_month VARCHAR. One unique reporting-carrier scheduled flight per origin/date/number/scheduled departure/destination; duplicates/corrections audited and deduped deterministically.
`airports`: airport VARCHAR PK, name, lat DOUBLE, lon DOUBLE, timezone VARCHAR, station VARCHAR nullable, focal BOOLEAN. `carriers`: carrier PK, name.
`rotations`: from_flight_id, to_flight_id, tail, airport (=first dest/next origin), sched_gap_min, actual_gap_min, inbound_arr_delay, outbound_dep_delay; validated retrospective contiguous same-tail chain, noncancelled/nondiverted, same airport, 20..360 scheduled gap, nonnegative actual gap, no overlapping actual flights. No forecasting features use tail assignments.
`features`: airport VARCHAR, cutoff TIMESTAMP UTC hourly; target_n INTEGER; target_rate DOUBLE (late15 OR cancellation / scheduled departures in [cutoff,cutoff+2h)); target_late_n INTEGER; label_available_at TIMESTAMP (latest of cutoff+14h and actual_dep+15min in target, so later if extreme); sched_n_2h DOUBLE; hour DOUBLE; dow DOUBLE; month DOUBLE; lag_rate_2h DOUBLE from departures observed <=cutoff-15min in trailing 2h, null if none; lag_rate_6h DOUBLE; observed_n_2h DOUBLE; backlog_n DOUBLE (scheduled [cutoff-6h,cutoff-15min], no observed departure by cutoff-15min, includes unknown cancellations); temp_c DOUBLE, wind_ms DOUBLE, visibility_m DOUBLE; weather_age_min DOUBLE; weather_available_at TIMESTAMP; max_event_available_at TIMESTAMP; upstream_rate DOUBLE (train-period scheduled route weighted average of other airports lag_rate_2h, fallback zero). Feature nulls kept; do not train on target_n=0.
All modeling in `cascade/modeling.py`, scenario engine in `cascade/simulation.py` owned by model agent. Agent may create `tests/test_modeling.py`, `tests/test_simulation.py`, and docs/MODEL_CARD.md. Entrypoints `modeling.run(db_path=Path(...), output_dir=Path('reports'))` and simulation.run same signature. Predictions table: airport, cutoff, model, prediction, target_rate, target_n, split, fold. Model summaries `reports/model_evaluation.json`. Scenario output `reports/scenarios.json`, db optional.
